# Cloud-Cybersecurity-lab

Notes et configurations de mon homelab — Cloud & Cybersécurité.

## À propos

Je suis étudiant en Cloud et Cybersécurité. Ce dépôt regroupe mes travaux pratiques, configurations et expériences réalisées dans un environnement de laboratoire virtuel.

## Domaines étudiés

- Administration Linux
- Réseaux informatiques
- Sécurisation des services
- Services réseau
- Stockage et gestion des disques
- Dépannage et analyse de pannes

## Projets réalisés

| Projet        | Description                                    |
| dns-bind9     | Configuration d'un serveur DNS avec BIND9      |
| ftp-vsftpd    | Installation et configuration d'un serveur FTP |
| openldap      | Configuration d'un annuaire LDAP               |
| raid1-lvm     | Mise en place de RAID 1 et LVM                 |
| raid1-panne   | Simulation et analyse d'une panne RAID 1       |

## Environnement de travail

- Linux
- Ubuntu Server
- Rocky Linux
- Kali Linux
- VirtualBox

## Objectif

Développer mes compétences pratiques en administration système, réseaux et cybersécurité, tout en documentant mes apprentissages.
